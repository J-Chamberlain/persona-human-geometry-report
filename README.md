# Persona–Human Geometry

Interactive research report comparing how three open language models (Qwen 3 32B, Gemma 2 27B and Llama 3.3 70B)
organize personality traits in their internal representations, and how that organization compares with people.

**Read the report:** https://j-chamberlain.github.io/persona-human-geometry-report/

Status: working draft for comment (November 2026). The report is a single self-contained page (`index.html`); it
loads nothing from outside and also opens directly from a downloaded copy.

Author: Josiah Chamberlain. Analysis and code were developed with AI assistants (Claude, Claude Code, GPT and Codex)
under the author's direction. Personas, trait list and released vectors: Lu et al. (2026), *The Assistant Axis*.

Built from the analysis notebook at source commit `c2f2591`.
